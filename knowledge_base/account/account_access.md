# Account Access Policy

## Overview

Customers may experience difficulty accessing their payment account because of incorrect login information, device changes, network issues, application problems, or account security restrictions.

## Unable to Log In

If a customer cannot log in, they should:

1. Verify that they are using the correct registered mobile number or login information.
2. Check their internet connection.
3. Ensure that the application is updated.
4. Follow the official account recovery process if they cannot access their account.

## Account Temporarily Restricted

If an account has been temporarily restricted for security reasons, the customer should follow the verification or recovery instructions displayed in the official application.

The AI assistant must not claim that it can remove a security restriction unless an authorized backend system provides that capability.

## New Device

If a customer is accessing their account from a new device, additional verification may be required.

The customer should complete only the verification steps shown through the official application.

## Security

Never ask customers for:

- Password
- OTP
- UPI PIN
- CVV
- Full card PIN

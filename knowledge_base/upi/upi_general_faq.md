# UPI General FAQ

## What is UPI?

UPI is a digital payment system that allows customers to make payments and transfer money through supported bank accounts and payment applications.

## UPI Payment Failed

If a UPI payment fails, the customer should first check the transaction status.

If money was deducted, the customer should avoid making the same payment again immediately and check whether the amount is subsequently reversed.

## UPI Payment Pending

If a UPI transaction is pending, the customer should wait for the transaction status to update before attempting another payment.

## UPI Payment Successful

If a UPI transaction shows as successful, the customer should retain the transaction ID for reference.

If the recipient or merchant claims they did not receive the money, the transaction details should be verified before making another payment.

## Security

Customers should never share:

- UPI PIN
- OTP
- Password
- CVV
- Full card PIN

The payment application or support team should never require the customer to disclose these credentials.

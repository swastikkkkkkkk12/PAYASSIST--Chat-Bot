# UPI Transaction Limits

## Overview

UPI transaction limits can depend on the bank, payment application, account type, transaction type, and applicable payment network rules.

## Customer Questions About UPI Limits

Customers may ask:

- What is my UPI transaction limit?
- How much can I send through UPI?
- Why can't I make a large UPI payment?
- Can I make multiple UPI transactions in one day?

## How to Handle Limit Questions

The support system should not assume a single universal transaction limit.

The customer's applicable limit should be determined using the relevant bank, account, payment method, and current payment service rules.

## If a UPI Payment Is Rejected Because of a Limit

The customer should:

1. Check whether the transaction exceeds the applicable limit.
2. Verify the bank or payment application's current transaction limits.
3. Try an alternative permitted payment method if appropriate.
4. Contact support if the customer believes the limit has been applied incorrectly.

## Important

The AI assistant must not invent or assume a transaction limit.

If the applicable limit is not available in the knowledge base, the assistant should clearly state that it does not have the required information and direct the customer to the appropriate official support channel.

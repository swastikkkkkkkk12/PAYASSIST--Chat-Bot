# Create Complaint Policy

## Overview

Customers can raise a complaint when they experience an unresolved payment, account, refund, security, or other service issue.

## Information Required

Depending on the issue, the customer may need to provide:

- Description of the problem
- Transaction ID, if applicable
- Transaction amount
- Transaction date
- Merchant or recipient information
- Relevant screenshots or documents, if requested through the official process

## Complaint Creation

The complaint should be created through the authorized support system.

After creation, the customer should receive a complaint or ticket reference number when the system supports it.

## AI Assistant Rule

The AI assistant must not claim that a complaint has been created unless the authorized complaint-management system confirms successful creation.

If complaint creation is unavailable, the assistant should explain that the customer needs to use the appropriate official support channel.

# Complaint Status Policy

## Overview

Customers can contact support to check the status of an existing complaint.

## Checking Complaint Status

The customer should provide the complaint or ticket reference number when available.

The support system can use the reference number to retrieve the current complaint status if the authorized backend system is connected.

## Possible Complaint Statuses

A complaint may have statuses such as:

- Open
- Under Review
- Awaiting Customer Information
- Resolved
- Closed

The exact status should be retrieved from the authorized support system.

## Important

The AI assistant must not invent a complaint status.

If the complaint record cannot be accessed, the assistant should tell the customer that it cannot verify the current status and direct them to the appropriate support channel.

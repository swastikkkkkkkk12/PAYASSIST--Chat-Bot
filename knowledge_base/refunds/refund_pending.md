# Refund Pending Policy

## Overview

A refund is considered pending when the refund process has been initiated but the amount has not yet been credited to the original payment source.

## Why Can a Refund Be Pending?

A refund may remain pending because of:

- Merchant processing
- Bank processing
- Payment network processing
- Transaction reconciliation
- Technical delays

## What Should the Customer Do?

The customer should:

1. Check the refund status in the payment application.
2. Verify the original transaction details.
3. Wait for the applicable refund processing period.
4. Contact support if the refund remains pending beyond the applicable processing period.

## Information Required for Support

The customer should keep:

- Original transaction ID
- Refund ID, if available
- Transaction amount
- Refund amount
- Transaction date
- Merchant name

## Important

The exact time required for a refund can vary depending on the merchant, bank, payment method, and payment network.

Support should not promise a specific refund time unless the applicable policy provides one.

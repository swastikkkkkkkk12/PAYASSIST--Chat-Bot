# Refund Failed Policy

## Overview

A refund is considered failed when the refund process could not be completed successfully.

## Possible Causes

A refund may fail because of:

- Bank side processing issues
- Payment network issues
- Incorrect or unavailable payment information
- Merchant side processing problems
- Temporary technical issues

## What Should the Customer Do?

The customer should:

1. Check the refund status.
2. Verify the original transaction.
3. Check whether the refund was attempted again.
4. Contact support if the refund remains unsuccessful.

## Information Required

The customer should provide:

- Original transaction ID
- Refund ID, if available
- Transaction amount
- Refund amount
- Transaction date
- Merchant name

## Security Rule

Customer support must never request:

- OTP
- UPI PIN
- Password
- CVV
- Full card PIN
